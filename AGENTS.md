# AGENTS.md

## Project Overview

Chinese classical novel reading site: 441 books (20,616 chapters) across 7 genres, 2 locales (zh / zh-TW). Static Astro site; all content lives under `site-content/`.

## Commands

```bash
# Rebuild site data from site-content/zh (metadata + zh-TW via OpenCC).
# --full is REQUIRED before `astro build` (generates zh-TW bodies + chapter indexes).
node site/site-build.mjs --full

cd site
pnpm dev      # dev server on :4321
pnpm build    # static output to site/dist/
pnpm check    # astro check (needs @astrojs/check + typescript)
```

There is no HTML→Markdown step anymore: `site-content/zh/` is the primary source of truth. `scripts/convert.py` is kept for reference only — its input (`source-data/`) was removed.

The former LLM translation pipeline (`scripts/translate.mjs`, en/ja locales) was removed — the site is Simplified + Traditional Chinese only. zh-TW is generated from zh via OpenCC in site-build; no machine-translation content remains.

## Directory Structure

- `site-content/zh/<bookType>/<bookName>/` — Simplified Chinese source of truth: `info.json`, `chapters.json`, `NNN.md` (zero-padded chapters)
- `site-content/zh-TW/<bookType>/<bookName>/` — Traditional Chinese, generated by site-build (OpenCC): `info.json` + `chapters.json` (converted fields) + bodies, cached — delete a book dir to force regeneration
- `site-content/books.json` — aggregated metadata for all books, generated by site-build (do not edit by hand)
- `site/` — Astro site (pnpm, TypeScript)

## Key Files

- `site/site-build.mjs` — scans `site-content/zh`, writes `books.json` + zh-TW mirror
- `site/src/lib/data.ts` — data loading: `readChapterBody(lang, bookId, file)`, `readChapters(bookId, locale)`; `BOOK_TYPE_LABEL(key)`
- `site/src/content.config.ts` — Astro content collection schema for `books`
- `site/src/i18n/ui.ts` — UI strings for zh / zh-TW

## Environment Variables

- `SHUGE_CONTENT` — override site-content directory (default: `../site-content`)

## Conventions

- Book IDs use format `<bookType>/<bookName>` (e.g., `世态人情/金瓶梅`); slugs are the bare book name
- Chapter files are zero-padded: `000.md`, `001.md`, …; first line of each file is `# <title>`
- Chapter indexes are per-language: zh-TW readers get converted titles when a per-book index exists; otherwise they fall back to zh
- Locales: `zh` and `zh-TW`; all routes live under `/[lang]/…`
- All content is in Chinese; code comments and config use English
